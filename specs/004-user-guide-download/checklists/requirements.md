- [x] Tập trung vào giá trị cho người vận hành; không quy định framework hoặc API mới.
- [x] Viết bằng tiếng Việt; tên nút và tên kỹ thuật giữ đúng sản phẩm.
- [x] Có tình huống, mức ưu tiên, yêu cầu, trường hợp biên và tiêu chí thành công.

## Mức đầy đủ

- [x] Không có điểm cần làm rõ còn treo.
- [x] Sáu yêu cầu kiểm thử được, có phạm vi và giả định rõ.

- [x] Bao quát file offline, mobile, bàn phím, backend lỗi và đóng gói.
