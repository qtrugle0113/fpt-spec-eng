# Dữ liệu tính năng

Không tạo bảng hoặc metadata mới. Một tài liệu static có tên `Airflow-Automation-Tool-Huong-dan-su-dung.html`, tiếng Việt, 16 mục và 12 ảnh nhúng.

Nguồn bàn giao ở `outputs/user-guide/`; bản phát hành ở `frontend/public/user-guide/`. Ràng buộc: bytes phải trùng nguồn. Builder ghi cả hai khi tái sinh; Vite đóng gói bản public. Không lưu lượt tải hoặc thay trạng thái nghiệp vụ.
